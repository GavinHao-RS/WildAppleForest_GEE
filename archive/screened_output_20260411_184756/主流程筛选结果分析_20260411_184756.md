## 三、特征筛选的原理与当前结果成因

### 1. 规则预筛

原理：
- 剔除高缺失特征
- 剔除近零方差特征

当前结果：
- `250 -> 250`

原因：
- 当前特征表整体完整度较高
- 在现有阈值下，没有特征因为缺失率或方差被排除

这说明当前规则预筛是“兜底环节”，不是当前特征压缩的主要来源。

### 2. `J-M` 可分性筛选

原理：
- 针对关键类别对，计算单个特征的可分性
- 当前重点类别对：
  - `Wild Apple Forest vs Other Forest`
  - `Wild Apple Forest vs Cropland`
  - `Wild Apple Forest vs Grassland/Shrub`

当前前列特征包括：
- `dist_to_valley_proxy_m`
- `elevation`
- `slope`
- 多个 `M04/M05` 光学特征
- 少量 `VV_VH_ratio`

原因：
- 野苹果林的区分，不仅来自冠层光谱，还强烈受生境约束
- 伊犁山区场景下，谷地距离、海拔、坡度天然有较强区分度
- 早春光学特征对林地、草灌、耕地分化也比较敏感

因此，`J-M` 当前更偏向：
- 地形/生境
- 早春光学

而不是优先保留大量拟合系数或 SAR。

### 3. RF 重要性筛选

原理：
- 在 `J-M` 筛后的子集上训练 grouped RF
- 用模型实际贡献度再做一次压缩

当前靠前的特征包括：
- `NDVI_mean`
- `NDVI_max`
- `elevation`
- `VH_db_std`
- `swir1_M07`
- `NDVI_M08`
- `slope`
- `EVI_M05`
- `GCVI_M05`

原因：
- RF 更关注“组合后的实际判别贡献”
- 部分地形、物候统计、关键月份原始波段在模型中共同发挥作用
- 这一步比单独的 `J-M` 更接近最终分类需求

### 4. 相关性剪枝

原理：
- 对高相关特征做保序去冗余
- 保留排序更靠前的那个，剔除后续高相关特征

当前被剪掉的特征包括：
- `swir1_M04`
- `BSI_M04`
- `NDMI_min`
- `NDBI_M04`
- `NDMI_M04`
- `LSWI_autumn_decline`
- `VH_db_amp`

原因：
- 它们与已保留特征高度相关
- 继续保留只会增加冗余，不一定增加判别力

### 5. 为什么最终会得到现在这样的特征结构

当前 [final_screened_features.csv](/d:/CODE/VS__Project/GEE/WildAppleForest_GEE/archive/screened_output_20260411_184756/final_screened_features.csv) 的结构明显偏：
- 光学时序
- 地形/谷地距离
- 少量 SAR
- 少量拟合特征

主要原因有三点：

1. 关键类别对本身就是“生境 + 光学节律”主导  
`J-M` 针对的是野苹果林与几个主要混淆类，这天然放大了地形与早春光学的权重。

2. 原始月序列特征数量更多，竞争优势更明显  
光学宽表特征很多，且与分类目标直接相关，拟合特征在当前规则下更容易被压到后面。

3. 拟合特征当前没有被单独保护  
它们只是普通候选特征的一部分，没有额外保留机制，因此在 `J-M` 与 RF 两轮竞争中更容易被光学原始特征压制。

## 四、是减少缓冲区采样，还是增加 WorldCover 其他类别样本

当前优先级应当是：
- 先收紧 `class 1` 缓冲区扩样
- 再有针对性地增加“难负样本”

不建议直接笼统增加所有 WorldCover 非目标类样本。

### 原因

1. 当前最明显的问题是 `class 1` 过量  
`904 vs 149` 的结构说明，野苹果类的训练像元占比仍然过高。

2. 后续面积计算更怕 `class 1` 假阳性  
如果正类先验过强，模型容易把相似林地、草灌边缘或局部裸地误吸进 `class 1`。

3. WorldCover 的价值取决于“加的是不是难样本”  
如果只是继续平均增加所有类样本点，可能只会增加容易类别，而不是增加真正会和野苹果林混淆的负样本。

### 当前建议

优先做这两件事：

1. 收紧缓冲区样本策略
- 减小缓冲半径
- 降低 `max_pixels_per_group`
- 或只对高纯度野苹果点保留缓冲扩样

2. 有针对性补充 hard negatives
- `Other Forest`
- `Grassland/Shrub`
- 野苹果林边界附近的相似地物
- 谷地附近但非野苹果林的林地/灌丛

因此，不是简单二选一，而是：
- 主动减少 `class 1` 的冗余缓冲像元
- 同时补充更有针对性的难负样本

## 五、如何让物候拟合特征发挥更大作用

当前拟合特征保留较少，并不代表它们无效，而是它们在当前筛选机制下竞争不过原始光学宽表特征。

如果希望物候拟合特征发挥更大作用，可以考虑以下方向：

### 1. 给拟合特征单独保留通道

当前做法是：
- 拟合特征与原始特征一起竞争

可改成：
- 先在拟合特征内部做一次筛选
- 强制保留前若干个拟合特征进入最终候选集

### 2. 降低原始月序列特征的数量优势

例如：
- 压缩部分高度冗余的逐月光学特征
- 让拟合特征和物候统计特征的相对权重上升

### 3. 在 `J-M` 阶段单独观察拟合特征排名

建议额外检查：
- 拟合特征在 `jm_feature_scores.csv` 中的排序位置
- 是否只是被数量更多的原始波段压制

### 4. 重新设计“保护性筛选”

例如：
- 最终特征集中至少保留若干个拟合特征
- 或分别从：
  - 光学原始特征
  - SAR 特征
  - 拟合特征
  - 地形特征
 里各取若干个

### 5. 更聚焦地为拟合特征服务

拟合特征更适合描述：
- 生长季形状
- 峰值前后变化
- 整体曲线平滑程度

如果后续目标更偏物候解释，而不是只追求像元精度，拟合特征应当被有意识地保留。

## 六、如果希望降低 class 1 假阳性，后续应重点关注什么

当前 `screened_model` 中：
- `class 1` precision 约 `0.846`
- `class 1` recall 约 `0.880`

这意味着：
- 已经不差
- 但如果进入整图分类，`class 1` 仍可能在空间上扩张，导致面积偏大

### 需要重点关注的方面

1. 样本结构  
优先控制 `class 1` 训练样本过量问题。

2. hard negatives  
重点补充与野苹果林最相似的负样本，而不是继续平均补齐所有类别。

3. 类别级评估指标  
后续不要只看 OA，要重点看：
- `class 1` precision
- `class 1` user accuracy
- `class 1` 假阳性来源

4. 后处理策略  
后续整图分类时需要更保守的：
- 空间平滑
- 最小斑块筛除
- 可能的高置信度阈值约束

5. 面积验证思路  
后续面积计算前，建议对：
- 高海拔区
- 谷地边缘区
- 与其他森林相邻区
做重点抽查，因为这些区域最容易让 `class 1` 面积虚高。

## 七、当前建议

下一步最合理的工作不是立刻做 SHAP，而是：

1. 优化样本策略
- 收紧 `class 1` 缓冲扩样
- 补充 hard negatives

2. 做一轮“保护拟合特征”的筛选实验
- 观察拟合特征是否能进入最终特征集并改善 `class 1` precision

3. 继续把关注点放在 `class 1` 假阳性控制上
- 因为这直接决定后续面积统计是否偏大
